## AI Usage
During the development of this Django Box Recommendation System, I used AI tools as a learning and debugging assistant. AI assistance helped me understand project requirements, explore Django concepts, identify errors, and improve my implementation.

The following sections describe the AI tools used, prompts provided, outputs accepted or modified, mistakes identified, and the steps taken to verify the final application.
## 1. Which AI tool(s) you used.
I used ChatGPT and Claude 

## 2. The prompts you gave.
1. Based on Company requirement for an assignment and 
give me a brief explanation about this
2. Create a professional and modern dashboard for my Django-based Box Recommendation System.with Products, Orders...etc
3. can you please help me plan to approach and i will try my own, Based on requirements tell me structure to start the project.
4. I need dummy product details and box details
5. How to connect both product and orders app
6. How to calculate the matching the box

## 3. What output you accepted.
I accepted the AI suggestions that helped me understand the project structure, Django models, views, templates, and URL configurations. I also used the suggestions for product management, order creation, box recommendations, dashboard design, and test cases. I reviewed the generated code, made changes according to my requirements, and kept the parts that worked correctly for my project.

## 4. What output you rejected or modified.
I rejected some AI-generated suggestions that were unnecessary or did not match my project requirements. I modified the HTML, CSS, dashboard layout, Django views, and templates to suit my design and functionality needs. I also corrected errors, adjusted the code to match my project structure, and made sure the final implementation worked as expected.

## 5. Any mistakes the AI made.
The AI sometimes suggested incorrect file paths, missing template configurations, and code that did not match my existing project structure. It also made a few mistakes in Django URL configurations, model relationships, and static CSS file linking. I reviewed the suggestions, fixed the errors, and tested the application to ensure everything worked correctly.

## 6. How you verified the final code.
I verified the final code by running the Django development server and manually testing all the features. I checked product creation, order management, box details, and box recommendations. I also tested different product dimensions and weights to ensure the system recommended suitable boxes. Finally, I ran the test cases, checked the database records, and fixed any errors found during testing.
